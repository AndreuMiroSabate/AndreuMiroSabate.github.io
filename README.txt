PÁGINAS INDEPENDIENTES — INSTRUCCIONES

1. Copia todos los archivos y carpetas de este paquete a tu repositorio.
2. Mantén las carpetas css/, js/, images/ y projects/ en la raíz.
3. Conserva tus imágenes originales dentro de images/. Este paquete no incluye las imágenes originales.
4. Edita projects/bound-by-death.html para cambiar los textos, imágenes y vídeos de Bound By Death.
5. Edita projects/project-two.html y projects/project-three.html para personalizar cada proyecto.
6. Para añadir una imagen, copia el archivo en images/ y usa:
   <img src="../images/nombre-de-tu-imagen.png" alt="Descripción">
7. Para añadir párrafos, usa <p>Tu texto</p>.
8. Los enlaces de Game Projects abren las páginas nuevas. Las tres tarjetas de Level Design
   siguen usando la plantilla anterior del index.html.
9. Abre index.html en tu navegador para probar. Luego sube los archivos a GitHub.

NOTA: Las rutas de imágenes bbd-level-01.png y bbd-level-02.png son ejemplos.
Reemplázalas con capturas reales o elimina las etiquetas hasta tenerlas.
