GAME PROJECT / 003

TRIBALB

01 / THE PROJECT

TribalB was my final degree project for my degree in videogame design and development at CITM. In this project I wanted to search if it was possible to teach the players how to play a survival game without using a conventional tutorial. The objective was to avoid using any text in the game, and use the environment, sounds and visual effects to teach the players, in a similar way the first level of Super Mario Bros does

02 / WhAT I DID

To be able to do this first I did an investigation about the tutorials in videogames, especially the survival ones, and how level design works. Once this investigation was done, I started building a prototype. With all the information, I started doing the design of the game, thinking about the meachincs, that would be necessary to build the tutorial.

After this the idea was to follow all the proces of designing a level starting with the investigation and research of references, then making flowmaps and layouts of the zones that the game will have. Once that was complete have a blockout to start testing the meachanics and finally add the assets to the game.

Once the prototype was finished I presented to some people and ask them what they thinkabout the game, and if they understand how to play.
